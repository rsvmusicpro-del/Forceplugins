# Plugins du projet

Ce dossier est l'emplacement obligatoire de tous les plugins développés dans ce dépôt pour Akai MPC et Force.

Créez un sous-dossier distinct par plugin et conservez-y ses sources, son interface, ses ressources et ses presets.

Exemple :

```text
plugins/
├── MonPremierPlugin/
└── MonDeuxiemePlugin/
```
